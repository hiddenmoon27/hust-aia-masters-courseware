## 优化理论考试说明

- **考试形式：** 半开卷考试。
- **考试时长：** 2.5 小时（150 分钟）。
- **可携带资料：** 一张 A4 纸，可提前在正反两面写好笔记，带入考场参考使用。

考核信息根据仓库维护者提供的课程情况记录。

## 目录说明

每门课程单独设置文件夹。优化理论文件夹提供课件索引，课件保留原有中英文内容；文件夹、课件文件名及说明使用中文。
