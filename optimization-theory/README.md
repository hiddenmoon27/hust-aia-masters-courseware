## Exam format

- **Format:** Semi-open-book examination with a prepared reference sheet.
- **Duration:** 2.5 hours (150 minutes).
- **Permitted reference material:** One A4 sheet. Notes may be prepared on both sides in advance and brought into the examination for reference.

## File notes

- Original PowerPoint formats are retained where supplied; chapter 2 is a macro-enabled PowerPoint file (.pptm).
- Chapter 3 is a 95-page PDF assembled from the online course slides.
- Byte-identical duplicate downloads have been omitted.
- Course materials include Chinese and English slides. Filenames and repository descriptions are in English.

Assessment details are recorded from information provided by the repository owner.
